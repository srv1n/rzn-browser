# Project overview

<!-- tusker:overview:begin -->

RZN Browser is a local browser automation tool. It runs JSON workflows in a
user's signed-in Chrome session. It includes a Rust CLI, a Rust native host,
and a Chrome extension. It also has an LLM planner for tasks that are not
known in advance.

This project covers the CLI, runtime, extension, workflow catalog, SDK,
release scripts, and developer documentation. It does not provide anonymous
crawling or a rented cloud browser. This vault is new and has no old epics or
tasks.
