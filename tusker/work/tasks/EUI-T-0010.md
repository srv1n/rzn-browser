# EUI-T-0010 · Allow dashboard tab supervisor RPC

## Intent

Allow the packaged extension dashboard to call supervisor RPCs when Chrome opens it in a normal tab, without granting content scripts or foreign extensions access to UI-only runtime commands.

## Acceptance

| ID | Outcome | Proof |
|---|---|---|
| A1 | Packaged extension pages are authorized regardless of whether Chrome attaches a tab to the sender. | Focused automated test |
| A2 | Same-extension content scripts, foreign extensions, and missing sender identity remain unauthorized. | Focused automated test |
| A3 | The extension bundle still builds. | Extension build |

## Non-goals

- Do not change native-host or macOS network permissions.
- Do not broaden content-script access to UI-only commands.
